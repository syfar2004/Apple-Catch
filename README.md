# 🍎 Apple Catch

A simple 2D apple-catching game built with **Godot Engine** as my first game development project.

The player moves left and right to catch falling apples. Each caught apple is removed and a new apple is spawned at a random position.

## 🎮 Current Features

- 2D game built with Godot
- Player movement using keyboard controls
- Falling apples
- Apple-player collision detection
- Apple respawning
- Random apple spawn positions
- Reusable Apple scene
- Signal-based communication between game objects

## 🛠️ Technologies

- Godot Engine
- GDScript
- Git
- GitHub
